# Algorithms & Problem Solving - Level 5 (Data Structures in C++)

This repository contains implementations of various custom Data Structures and Projects developed in C++ as part of **Algorithms & Problem Solving Level 5**.

---

## 📁 Repository Structure

| Project | Description | Core Classes / Files |
| :--- | :--- | :--- |
| **Project 1** | Doubly Linked List implementation | `clsDblLinkedList.h`, `main.cpp` |
| **Project 2** | Queue implementation using Doubly Linked List | `clsMyQueue.h`, `clsMyQueueVer2.h`, `main.cpp` |
| **Project 3** | Stack implementation using Doubly Linked List | `clsMyStack.h`, `main.cpp` |
| **Project 4** | Dynamic Array implementation | `clsDynamicArray.h`, `main.cpp` |
| **Project 5** | Queue implementation using Dynamic Array | `clsMyQueueArr.h`, `main.cpp` |
| **Project 6** | Stack implementation using Dynamic Array | `clsMyStackArr.h`, `main.cpp` |
| **Project 7** | Custom String Class with Undo / Redo operations | `clsMyString.h`, `main.cpp` |
| **Project 8** | Queue Line / Service Tickets Simulation System | `clsQueueLine.h`, `clsQueueLineVer02.h`, `MyDate/` |

---

## 🛠️ How to Compile & Run

You can compile any project using `g++`:

```bash
# Example for Project 1:
cd Project1
g++ -std=c++17 main.cpp -o main
./main
```
